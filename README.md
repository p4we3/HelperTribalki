# HelperTribalki

Planer ataków do Tribal Wars 2 w jednym pliku `index.html`:

- **Planer wysyłek**: wpisujesz wioski z offem i cele, planer liczy dystans na mapie heksagonalnej, czas marszu najwolniejszej jednostki i godzinę wysyłki.
- **Kalkulator walki**: obrona celu kontra ataki z kilku wiosek, straty i ile wojska zostaje.
- **Koszty wojsk**: ile drewna, gliny i żelaza kosztuje rekrutacja.

Strona nie potrzebuje serwera. Żeby ją opublikować, włącz GitHub Pages (Settings → Pages → gałąź `main`, folder `/`).
